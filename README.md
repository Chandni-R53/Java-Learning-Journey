### About

This repo covers my Java learning — building familiarity with the language through core concepts, OOP principles, and practical exercises. Each folder covers a specific topic, practiced independently with examples.

---

### Topics Covered

- Java Basics — syntax, data types, variables, operators
- Input / Output using Scanner
- Conditional statements and loops
- Arrays and array utilities
- Methods and access modifiers
- Object-Oriented Programming — classes, objects, constructors, encapsulation, inheritance, polymorphism, abstraction
- Exception handling — try/catch, custom exceptions
- File handling
- String operations and type conversion
